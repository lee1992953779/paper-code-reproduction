## 每篇论文的目录结构

```text
论文目录/
├── README.md    # 论文信息、阅读重点、代码入口和复现状态
└── code/        # 指向个人 Fork 的代码子模块（TOLF 暂无）
```

`code/` 保留上游项目的历史、许可证和原始说明。进入对应目录即可查看官方代码。

## 下载全部代码

```bash
git clone --recurse-submodules https://github.com/lee1992953779/paper-code-reproduction.git
```

如果已经克隆了总仓库，在总仓库目录运行：

```bash
git submodule update --init --recursive
```

## 复现记录方式

每篇论文按以下顺序推进，并把真实结果补充到相应目录：

1. 阅读动机、方法图和消融实验，记录准备验证的问题。
2. 按上游说明整理环境、数据集和评价指标。
3. 先运行推理或小规模检查，再进行正式训练。
4. 保存实际配置、日志、模型和结果对比，注明与论文设定的差异。

本仓库当前用于收录和安排复现，尚未完成环境配置、训练或论文指标验证。TOLF 单独保留论文说明，待确认官方代码后再补充。
